# Dungeon Survivor

横屏 2D 像素风开放大地图动作地牢游戏。

## 当前版本

- 浏览器 HTML 直接运行，不需要 EXE
- 1280×720 横屏画面
- 3600×2400 开放大地图
- 58 个小怪同时分布在地图
- 哥布林、骷髅、野狼三种小怪
- 狼王 Boss 与小怪同场
- WASD / 方向键移动
- 鼠标左键攻击
- Shift 闪避
- 护身轮转剑，可点击右上角按钮或按 1 开关
- 护身剑自动环绕并攻击靠近的敌人
- 攻击斩击、命中特效、伤害数字、暴击、Boss 弹幕
- 经验升级与随机强化
- 金币掉落
- 小地图显示敌人和 Boss 位置
- 手机虚拟摇杆与攻击按钮

## 运行

直接打开 index.html 或 game.html。

也可以使用 GitHub Pages 在线运行。

## 操作

WASD / 方向键：移动  
鼠标左键：攻击  
Shift：闪避  
1：护身轮转剑 开 / 关  
R：死亡或胜利后重新开始
