# Dungeon Survivor

一个无需外部素材即可运行的横屏 2D 地牢闯关小游戏。

## 当前版本

- 横屏 1280×720
- WASD 移动
- 鼠标左键攻击
- Shift 闪避
- 房间清怪后进入出口
- 经验与升级
- 6 种随机升级
- 金币掉落
- 普通敌人与 Boss
- 每 5 层出现 Boss
- 死亡与重新挑战
- 触屏虚拟摇杆与攻击按钮

## 运行

直接打开 `index.html` 即可游玩。
